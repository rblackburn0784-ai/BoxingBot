# BoxingBot V2.0

A Discord boxing game built on the stabilised V1.9 combat engine.

The main player entry point is `/menu`. Players own one linked boxer, build a persistent career, settle grudge matches, earn achievements and compete in persistent tournaments. Admins run the game through the V2 Admin Centre while legacy slash commands remain available for direct fight control.

V2 deliberately separates **progression** from **power**: level, XP, prestige, championships and achievements are permanent status/progression systems, but all fighters remain inside the same 60-point competitive budget with 100 HP.

See `V2.0_RELEASE_NOTES.md` for the complete feature list and `RUN_V2_CHECKLIST.md` before the first live server run.
